# Helmlink App Conceptual Design

Helmlink is a helmet addition to e-bikes, which provides the option for increased safety at no extra cost. This repository therefore documents the conceptual design of an application addition to existing e-bike interfaces.

- Helmlink takes a safety-centric approach to the global rise in e-bike use with its simple add-on to existent e-bike apps (such as Lime, Voi etc.).
- Upon use of Helmlink, the ride only stops post reattachment and locking of the helmet.

Conceptual app add-on can be found here: https://kavro-bike-app-4yw8.vercel.app/
